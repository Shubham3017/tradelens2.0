# tradelens2.0
A full-stack trading journal with behavioral analytics, trader profiling, and data-driven insights built with Spring Boot, React, and MySQL.

TradeLens 2.0 is a full-stack trading journal application that helps traders 
track performance, analyze behavioral patterns, and improve discipline through 
data-driven insights.

Built with Spring Boot 3.5.14, React, MySQL, and Docker.

Features:
- Trade CRUD with auto P&L calculation
- Equity curve and win/loss analytics
- Behavioral insight engine (overtrading, revenge trading detection)
- Trader profile scoring (win rate, R:R, discipline, profitability)
- Profit factor and expectancy metrics
- JWT authentication
- Dockerized with 3 containers
- CI/CD with GitHub Actions
